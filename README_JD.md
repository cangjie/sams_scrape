## 新电脑上要有

- 一个能在京东页面里执行 JS、并且能一直开着标签页的浏览器。之前用的是 Claude 桌面版的内置浏览器；换成 Codex 等别的工具时，用它能操控的 Chromium 浏览器，或者普通 Chrome 的开发者工具控制台手动粘贴，都可以。下面「在页面里执行」指的就是这个。换了浏览器 localStorage 是空的，第 3 步的装回必须做。
- Python 3，装有 openpyxl（只有导出 Excel 要用）。脚本第一行写的是 `/usr/local/bin/python3`，路径不同就用 `python3 脚本名` 运行。
- 在这个浏览器里登录京东。这一步要本人做。

## 步骤

1. 把整个 `sams_scrape/` 目录拷过去（可以不带 `data/shots/`）。
2. 起两个本机服务（都只监听 127.0.0.1）：
   - `python3 jd_receiver.py`
   - `python3 jd_state.py`
3. 把状态装回浏览器：
   - 浏览器打开 `http://127.0.0.1:8767/import`，它会带着状态自动跳到 `https://mall.jd.com/misc/js/tab-3.js`。
   - 到了之后在这个页面里执行 `python3 jd_state.py js` 打印出来的「装回」那段 JS。应返回 `{keys: 19, rows: 1006, sent: "1006"}`。
4. 续跑：在停着 `tab-3.js` 的那个标签页里执行 `eval(localStorage.__jdp_src)`。这个标签页要一直开着，脚本在里面定时开页取价。
5. 看进度：`window.__jdp` 的 `got / calls / pages / blocked / stopped / done`，日志在 `localStorage.__jdp_log`。
6. 落盘：**另开一个标签页**打开 `tab-3.js`，执行 `jd_transfer.js` 的内容；页面跳到本机、标题变成 `jd-recv {"saved": N}` 后，把这个标签页再导回 `tab-3.js`。新行不多，一次就送完（返回 `{done: true}` 表示没有新行）。不要在跑脚本的那个标签页里做，会把它跳走。
7. 取完（`__jdp.done`）或者中途想要一版：`python3 jd.py status` 核对数量，`python3 scrape.py export` 导出。

改了 `jd_price.js` 之后要重新送进页面（`localStorage.__jdp_src`）：临时 `python3 -m http.server 8766 --bind 127.0.0.1`，
第二个标签页打开 `http://127.0.0.1:8766/jd_price.js`，fetch 出文本后跳到 `tab-3.js#` + encodeURIComponent(文本)，
在那边解出来存进去并核对 SHA-256；换新脚本前先把旧实例停掉（`__jdp.stopped = '…'`，等 `__jdp.run` 结束）。

## 两台电脑不要同时跑

状态只有一份。在新电脑上续跑之后，这台电脑浏览器里的状态就旧了。要换回来，在新电脑上导出
（mall.jd.com 页面里执行 `jd_state.py js` 的「导出」那段），把 `data/jd_browser_state.json` 和 `data/jd_items.jsonl` 拷回来再装回。

## 限速：实测到的情况

换电脑不一定更快。被收紧的多半是京东账号（10-11 第一轮抓得太快之后一直是这样），不是这台机器。

- 分类页的商品列表走 `moduleHtmlColor`，价格走 `mGetsByColor`（一次最多 10 个商品）。被挡时返回 403，页面没有验证码也不是掉登录。
- 取价请求带的加密编号每次开页都换，存下来的旧编号不能用：缺价商品在哪一页就得开哪一页。
- 开页间隔：10-11～12 的 126 次开页记录里，隔 10～16 分钟开的通了五成多，隔 26～31 分钟的 22 次通了 19 次。现在用 27 分钟。
- 任何一次 403（开页或取价）之后短时间内再取价基本都被挡。现在的做法：关掉页面，静默 62 分钟再重新开页。
- 10-13 一晚上的实际表现：01:26～01:31 通 2 页；01:36～03:16 开页被挡 3 次；04:19～05:19 连通 3 页 65 个；之后 05:23、06:54 取价各被挡一次；
  07:57 一次页面没打开（没查清是网络还是验证页）。6 个半小时补了 75 个。看不出能预测的规律，只有凌晨 4～5 点明显顺。
- 不要做的事：被挡后分钟级重试（会被收得更紧）；把 iframe 拉高让页面自己成批取价；连着失败时不换对象验证就认定「被封了」。
- 同一个 iframe 里连着第三次 403，京东会把它跳去别的域名（多半是验证页）。遇到验证页要本人处理。
