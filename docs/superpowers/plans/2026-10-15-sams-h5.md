# 山姆商品查询 H5 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 用 `sams_scrape` 抓到的山姆 App 商品做一组手机网页，放在 `https://mini.snowmeet.top/sams/`。店员能按分类浏览、按名字搜索，看到图、规格、价格和有没有货。

**Architecture:**
- `sams_site.py build` 读 `data/items.jsonl`、`data/jd_items.jsonl`、京东主图和 App 截图，在 `dist/` 生成静态网站：带指纹的 JSON 数据文件、商品图、`index.html`、带指纹的 js/css。
- `sams_site.py publish` 经美国服务器 2222 转发，把 `dist/` 传到 mini 服务器，再用实例角色同步进 S3 的 `upload/sams/`。
- mini 服务器的 nginx 把 `/sams/` 转给 CloudFront（`img.snowmeet.top`）。
- 不碰 SnowmeetApi，不用数据库。
- 截图的识别结果按截图内容缓存在 `cache/ocr/`。以后重新生成时，只识别新的或内容变了的截图。

**Tech Stack:**
- Python 3.12（`/usr/local/bin/python3`，Pillow 12、openpyxl），`unittest`
- 原生 HTML/CSS/JavaScript，Node 20 自带的 `node:test`
- macOS Vision（`src/analyze.swift`）
- rsync、aws-cli 1.22（mini 服务器上）、nginx

**Spec:** `docs/superpowers/specs/2026-10-15-sams-h5-design.md`

```python
def analyze_raw(path):
    """识别一张截图，返回 bin/analyze 的原始结果（dict）；识别失败返回 None。"""
    t = time.time()
    raw = Ocr.ask(path)
    if raw is not None and "error" in raw:
        # 系统给识别程序建的模型缓存坏了（在命令沙箱里跑过一次就会留下空的缓存条目，之后每张图都失败）。
        # 清掉缓存、重启识别进程再试一次；重建缓存的那一张会慢二三十秒。
        import shutil
        Ocr.close()
        shutil.rmtree(OCR_CACHE, ignore_errors=True)
        log("  ⚠ 识别模型缓存损坏，已清理并重建")
        raw = Ocr.ask(path)
    if time.time() - t > 10:
        log(f"  ⚠ 这一页识别用了 {time.time() - t:.0f} 秒（识别模型刚加载时会这样）")
    if raw is None or "error" in raw:
        return None
    return raw


def analyze(path):
    raw = analyze_raw(path)
    return None if raw is None else Page(raw, path)
```

### Task 2：去重和京东配对抽成可复用的函数

网站和 Excel 要用同一份「去重后的商品」和同一套京东配对。现在的情况：
- 去重写在 `scrape.export()` 里面；
- 配对结果被 `compare.compare()` 吃掉，只剩统计。

这一步把它们抽出来，导出 Excel 的结果不变。

**Files:**
- Modify: `scrape.py`（`merged_items()` 后面新增两个函数；`export()` 开头那段排序和去重换成调用）
- Modify: `compare.py`（`compare()` 拆出 `match()`）
- Modify: `.gitignore`（加 `dist/`、`cache/`）
- Create: `tests/test_regression.py`

**Interfaces:**
- Produces：
  - `scrape.category_order(state=None) -> tuple[list[str], dict[tuple[str, str], int]]`：返回大类顺序，以及 `{(大类, 子分类): 序号}`。
  - `scrape.unique_items(items=None, state=None) -> list[dict]`：去重后的商品，按分类顺序排列。每项是第一条记录的副本，另外带：
    - `dup`：其他所在分类，`["大类/子分类", ...]`；
    - `members`：合并进来的全部原始记录，含第一条；
    - `tags`：合并后的标签；
    - `jisuda`、`oos`：任一条记录为真就为真。
  - `compare.match(app_items, jd_items) -> tuple[list[tuple[int, int, float]], dict, dict]`：返回 `(pairs, near_a, near_j)`。
    - `pairs` 是 `[(App 下标, 京东下标, 名字相似度)]`，相似度在 0.15～1 之间；
    - `near_a`、`near_j` 与原 `compare()` 内部的同名字典相同。

当前数据的基准（10-15 实测）：
- 去重后 4604 个商品；
- 配上 745 对，涉及 App 商品 739 个；
- 只在 App 上的 3865 个，只在京东上的 17 个。

- [ ] **Step 3：在 `scrape.py` 的 `merged_items()` 后面加两个函数**

```python
def category_order(state=None):
    """(大类顺序, {(大类, 子分类): 序号})，按抓取时 state.json 里的顺序。"""
    state = load_state() if state is None else state
    order = {}
    for top, st in state.get("tops", {}).items():
        for i, s in enumerate(st.get("subs", [])):
            order[(top, s)] = i
    return list(state.get("tops", {})), order


def unique_items(items=None, state=None):
    """按分类顺序排好、合并重复后的商品（Excel「商品」表就是它）。
    App 是按大类抓的，同一个商品会挂在几个大类下（个护美妆 + 全球购、乳品烘焙 + 营养早餐……），各抓到一次。
    标题和价格都一样的只留一个（排在前面的那个大类），别的分类记在 dup 里；极速达 / 无货有一处是就算是；标签合并。
    members 是合并进来的全部原始记录（含第一条）。"""
    items = merged_items() if items is None else items
    tops, order = category_order(state)
    items = sorted(items, key=lambda it: (tops.index(it["top"]) if it["top"] in tops else 99,
                                          order.get((it["top"], it["sub"]), 999), it["id"]))
    uniq, seen = [], {}
    for it in items:
        key = (norm(it["title"]), it["price"])
        if key in seen:
            first = seen[key]
            first["dup"].append(f"{it['top']}/{it['sub']}")
            first["members"].append(it)
            first["jisuda"] = first.get("jisuda") or it.get("jisuda")
            first["oos"] = first.get("oos") or it.get("oos")
            first["tags"] = first.get("tags", []) + [t for t in it.get("tags", []) if t not in first.get("tags", [])]
            continue
        seen[key] = dict(it, dup=[], tags=list(it.get("tags", [])), members=[it])
        uniq.append(seen[key])
    return uniq
```

```python
"""山姆商品查询 H5 的数据：把去重后的 App 商品整理成网页要的 JSON。
结构见 docs/superpowers/specs/2026-10-15-sams-h5-design.md 第 6 节。这里只做计算，不读写文件。"""
import re

import scrape

TAG_SPLIT = re.compile(r"[｜|]|\s+")
TAG_TRIM = " ：:】【[]「」|｜"           # OCR 常把标签边上的竖线、括号一起认进来


def product_id(product):
    """商品 id：a + 合并进来的各条记录里最小的 id。重新生成时保持不变。"""
    return f"a{min(m['id'] for m in product['members'])}"


def split_tags(tags):
    """标签拆成小块、去掉边上的符号并去重：「进口｜限购6件」→ 进口、限购6件。「单位价 ¥2.6/瓶」整个保留。"""
    out = []
    for t in tags:
        for part in ([t] if t.startswith("单位价") else TAG_SPLIT.split(t)):
            part = part.strip(TAG_TRIM)
            if part and part not in out:
                out.append(part)
    return out


def out_of_stock(product):
    return bool(product.get("oos")) or any(w in t for t in product.get("tags", []) for w in scrape.STOCK_WORDS)


def product_cats(product):
    """商品所在的 (大类, 子分类)，第一个是主分类。合并进来的每条记录的分类，以及记录上「也在」的子分类都算。"""
    out = []
    for m in product["members"]:
        for sub in [m["sub"]] + list(m.get("also", [])):
            key = (m["top"], sub)
            if sub and key not in out:
                out.append(key)
    return out


def categories(products, top_order, sub_order):
    """分类表 [{name, subs: [{name, n}]}]，和 {(大类, 子分类): (大类序号, 子分类序号)}。
    顺序按抓取时的顺序；没有商品的子分类不列。"""
    counts = {}
    for p in products:
        for key in product_cats(p):
            counts[key] = counts.get(key, 0) + 1
    tops = sorted({t for t, _ in counts}, key=lambda t: (top_order.index(t) if t in top_order else 99, t))
    cats, index = [], {}
    for ti, top in enumerate(tops):
        subs = sorted((s for t, s in counts if t == top), key=lambda s: (sub_order.get((top, s), 999), s))
        cats.append({"name": top, "subs": [{"name": s, "n": counts[(top, s)]} for s in subs]})
        for si, s in enumerate(subs):
            index[(top, s)] = (ti, si)
    return cats, index


def to_item(product, index, image):
    """一个商品的 JSON。image 是 (缩略图路径, 大图路径) 或 None。"""
    name, spec = scrape.split_spec(product["title"])
    return {
        "id": product_id(product),
        "n": name,
        "s": spec,
        "p": product["price"],
        "d": product.get("desc", ""),
        "t": split_tags(product.get("tags", [])),
        "x": 1 if product.get("jisuda") else 0,
        "o": 1 if out_of_stock(product) else 0,
        "c": [list(index[k]) for k in product_cats(product)],
        "it": image[0] if image else "",
        "il": image[1] if image else "",
    }


def app_date(products):
    days = sorted({m["at"][:10] for p in products for m in p["members"] if m.get("at")})
    return days[0] if len(days) == 1 else f"{days[0]}～{days[-1]}"


def build(products, top_order, sub_order, images, generated):
    """整个数据文件。images 是 {商品 id: (缩略图, 大图)}，没有图的商品不在里面。"""
    cats, index = categories(products, top_order, sub_order)
    items = [to_item(p, index, images.get(product_id(p))) for p in products]
    meta = {"app_date": app_date(products), "generated": generated, "count": len(items)}
    return {"meta": meta, "cats": cats, "items": items}


def check(data):
    """生成后的自检。返回问题列表，空列表表示通过。"""
    problems, ids, seen = [], set(), {}
    for it in data["items"]:
        if it["id"] in ids:
            problems.append(f"{it['id']} 重复")
        ids.add(it["id"])
        if not it["n"]:
            problems.append(f"{it['id']} 没有商品名")
        if not isinstance(it["p"], (int, float)) or it["p"] <= 0:
            problems.append(f"{it['id']} 价格不对：{it['p']}")
        if not it["c"]:
            problems.append(f"{it['id']} 没有分类")
        for ti, si in it["c"]:
            seen[(ti, si)] = seen.get((ti, si), 0) + 1
    for ti, top in enumerate(data["cats"]):
        for si, sub in enumerate(top["subs"]):
            if seen.get((ti, si), 0) != sub["n"]:
                problems.append(f"{top['name']}/{sub['name']} 商品数 {sub['n']}，实际 {seen.get((ti, si), 0)}")
    return problems
```

```python
"""山姆商品查询 H5 的商品图：京东主图缩成两种尺寸，其余从 App 截图里裁（设计文档第 7 节）。"""
import difflib
import hashlib
import io
import json
from pathlib import Path

from PIL import Image

import scrape

ROOT = Path(__file__).resolve().parent
SHOTS = scrape.DATA / "shots"
OCR_DIR = ROOT / "cache" / "ocr"                    # 截图的识别结果，按截图内容缓存
JD_SIZES = {"t": 200, "l": 600}
CARD_IMG = scrape.LIST_X_MIN - scrape.IMG_X_MIN     # 商品图那一列的宽度（基准布局坐标，85）
IMG_ABOVE = 14                                      # 商品图上沿在标题上方多少（基准布局坐标）
WHITE = 245                                         # 比这更白的算背景


def jpeg_bytes(im, quality=82):
    buf = io.BytesIO()
    im.convert("RGB").save(buf, "JPEG", quality=quality, optimize=True, progressive=True)
    return buf.getvalue()


def named(pid, data):
    """文件名 <商品 id>-<内容指纹前 8 位>.jpg：图片一变文件名就变，CDN 不会给旧图。"""
    return f"{pid}-{hashlib.sha1(data).hexdigest()[:8]}.jpg"


def jd_versions(src):
    """京东主图 → {"t": 200×200 的 JPEG, "l": 600×600 的 JPEG}"""
    im = Image.open(src).convert("RGB")
    return {k: jpeg_bytes(im.resize((n, n), Image.LANCZOS)) for k, n in JD_SIZES.items()}


def trim_square(im):
    """切掉四周的白边，再用白色补成正方形，商品居中。整张都是白的返回 None。"""
    mask = im.convert("L").point(lambda v: 0 if v > WHITE else 255)
    box = mask.getbbox()
    if not box:
        return None
    im = im.convert("RGB").crop(box)
    side = max(im.size)
    out = Image.new("RGB", (side, side), "white")
    out.paste(im, ((side - im.size[0]) // 2, (side - im.size[1]) // 2))
    return out


def ocr_raw(path):
    """截图的识别结果（bin/analyze 的原始输出），缓存在 cache/ocr/ 下。
    缓存里记着截图内容的指纹：重新抓取后同名截图内容变了，会重新识别。识别失败返回 None，不缓存。"""
    sha = hashlib.sha1(path.read_bytes()).hexdigest()
    cache = OCR_DIR / (str(path.relative_to(SHOTS)) + ".json")
    if cache.exists():
        saved = json.loads(cache.read_text(encoding="utf-8"))
        if saved.get("sha1") == sha:
            return saved["raw"]
    raw = scrape.analyze_raw(path)
    if raw is None:
        return None
    cache.parent.mkdir(parents=True, exist_ok=True)
    cache.write_text(json.dumps({"sha1": sha, "raw": raw}, ensure_ascii=False), encoding="utf-8")
    return raw


def find_card(cards, title, price):
    """截图里对应这个商品的那张卡：价格相同，标题一样或八成像（同 scrape.Store.find 的规则），取最像的。"""
    n, best = scrape.norm(title), None
    for c in cards:
        if c["price"] != price:
            continue
        m = scrape.norm(c["title"])
        r = 1.0 if m == n else difflib.SequenceMatcher(None, m, n).ratio()
        if r >= 0.8 and (best is None or r > best[0]):
            best = (r, c)
    return best[1] if best else None


def visible_cards(page):
    """本页商品图完整露出的卡：图的上沿在表头下面，下沿在底部标签栏上面。"""
    hdr, tab = page.header(), page.tab_y()
    if hdr is None or tab is None:
        return []
    top = hdr["y"] + hdr["h"]
    return [c for c in scrape.parse_cards(page, at_top=True, strict=False)
            if c["y"] - IMG_ABOVE >= top and c["y"] - IMG_ABOVE + CARD_IMG <= tab]


def crop_card(shot_img, card):
    """裁出这张卡左边的商品图：从标题上方 IMG_ABOVE 开始，宽高都是 CARD_IMG（基准布局坐标）。"""
    sx, sy = shot_img.size[0] / scrape.BASE_W, shot_img.size[1] / scrape.BASE_H
    y0 = card["y"] - IMG_ABOVE
    box = (round(scrape.IMG_X_MIN * sx), round(y0 * sy),
           round(scrape.LIST_X_MIN * sx), round((y0 + CARD_IMG) * sy))
    return trim_square(shot_img.crop(box))


def crop_for(product):
    """给一个 App 商品从截图里裁图：依次试它每条记录的截图，返回 JPEG 字节；都裁不出来返回 None。"""
    for m in product["members"]:
        path = SHOTS / m["shot"]
        if not path.exists():
            continue
        raw = ocr_raw(path)
        if raw is None:
            continue
        card = find_card(visible_cards(scrape.Page(raw, path)), m["title"], m["price"])
        if card is None:
            continue
        im = crop_card(Image.open(path).convert("RGB"), card)
        if im is not None:
            return jpeg_bytes(im, quality=88)
    return None
```

```javascript
/* 山姆商品查询 H5 的纯函数：搜索、路由、格式化。浏览器里是 window.SamsLib，Node 里 require 得到同一组函数。 */
(function (root) {
  "use strict";
  const LIMIT = 200;
  const PLACEHOLDER = "data:image/svg+xml;charset=utf-8," + encodeURIComponent(
    '<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 100 100"><rect width="100" height="100" fill="#f2f3f5"/>' +
    '<text x="50" y="56" font-size="14" text-anchor="middle" fill="#b0b4ba">暂无图片</text></svg>');

  // 比较前统一：全角转半角（NFKC）、各种撇号统一成 '、转小写、连续空白并成一个
  function normalize(s) {
    return String(s == null ? "" : s).normalize("NFKC").replace(/[’‘`´]/g, "'")
      .toLowerCase().replace(/\s+/g, " ").trim();
  }

  function tokens(q) {
    const n = normalize(q);
    return n ? n.split(" ") : [];
  }

  // 每个词都要出现在商品名、规格或卖点里。最多返回 limit 条，total 是全部命中数
  function search(items, q, limit) {
    const max = limit || LIMIT, toks = tokens(q);
    if (!toks.length) return { results: [], total: 0 };
    const results = [];
    let total = 0;
    for (const it of items) {
      if (it._h === undefined) it._h = normalize([it.n, it.s, it.d].join(" "));
      if (toks.every(t => it._h.includes(t))) {
        total++;
        if (results.length < max) results.push(it);
      }
    }
    return { results, total };
  }

  // 搜索结果上方的提示；不需要提示时返回空串。空查询由页面显示首页的大类，不走这里
  function searchMessage(q, total) {
    if (total === 0) return `没有找到「${String(q).trim()}」`;
    if (total > LIMIT) return `结果太多，请再加一个词（共 ${total} 个）`;
    return "";
  }

  function searchHref(q) {
    return tokens(q).length ? "#/s/" + encodeURIComponent(String(q).trim()) : "#/";
  }

  function decode(s) {
    try { return decodeURIComponent(s); } catch (e) { return s; }
  }

  function parseRoute(hash) {
    const parts = String(hash || "").replace(/^#\/?/, "").split("/");
    const num = s => (/^\d+$/.test(s || "") ? Number(s) : null);
    if (parts[0] === "c" && num(parts[1]) !== null) return { page: "cat", top: num(parts[1]), sub: num(parts[2]) || 0 };
    if (parts[0] === "p" && parts[1]) return { page: "item", id: decode(parts[1]) };
    if (parts[0] === "s") return { page: "search", q: decode(parts.slice(1).join("/")) };
    return { page: "home" };
  }

  function formatPrice(p) {
    const [int, dec] = String(Math.round(p * 100) / 100).split(".");
    return "¥" + int.replace(/\B(?=(\d{3})+(?!\d))/g, ",") + (dec ? "." + dec : "");
  }

  function esc(s) {
    return String(s == null ? "" : s).replace(/[&<>"']/g,
      c => ({ "&": "&amp;", "<": "&lt;", ">": "&gt;", '"': "&quot;", "'": "&#39;" })[c]);
  }

  function imgSrc(item, large) {
    return (large ? item.il || item.it : item.it) || PLACEHOLDER;
  }

  const api = { LIMIT, PLACEHOLDER, normalize, tokens, search, searchMessage, searchHref, parseRoute,
                formatPrice, esc, imgSrc };
  if (typeof module !== "undefined" && module.exports) module.exports = api;
  else root.SamsLib = api;
})(typeof self !== "undefined" ? self : this);
```

```javascript
/* 山姆商品查询 H5：加载数据，按地址 # 后面的部分渲染首页、分类、搜索、详情四种页面。纯函数在 lib.js（window.SamsLib）。
   站内跳转都用 history.pushState / replaceState，自己渲染；浏览器返回键触发 hashchange 再渲染。
   每条历史记录带 {d: 站内第几层}：d>0 时左上角返回用 history.back()；从分享链接直接打开（d=0）时回首页，不会退出网站。 */
(function () {
  "use strict";
  const L = window.SamsLib;
  const app = document.getElementById("app");
  const scrolls = {};                     // 每个地址离开时的滚动位置，返回时恢复
  const byId = {}, bySub = {};
  let data = null, topCounts = [], current = null, lastDepth = 0, timer = null;

  function depth() { return (history.state && history.state.d) || 0; }

  function go(href, replace) {
    if (replace) history.replaceState({ d: depth() }, "", href);
    else history.pushState({ d: depth() + 1 }, "", href);
    render();
  }

  function goBack(fallback) {
    if (depth() > 0) history.back();
    else go(fallback, true);
  }

  function bar(inner) { return `<div class="bar">${inner}</div>`; }
  function backLink(href) { return `<a class="back" href="${href}" data-back aria-label="返回">‹</a>`; }
  function note() { return `<div class="note">价格为 ${L.esc(data.meta.app_date)} 山姆 App 快照，仅供参考</div>`; }
  function stateTags(it) {
    return (it.x ? '<span class="tag fast">极速达</span>' : "") + (it.o ? '<span class="tag oos">无货</span>' : "");
  }

  function row(it) {
    return `<a class="row${it.o ? " oos" : ""}" href="#/p/${encodeURIComponent(it.id)}">
      <img loading="lazy" alt="" src="${L.esc(L.imgSrc(it, false))}" onerror="this.onerror=null;this.src=SamsLib.PLACEHOLDER">
      <div class="info"><div class="name">${L.esc(it.n)}</div><div class="spec">${L.esc(it.s)}</div>
      <div class="price">${L.formatPrice(it.p)}</div><div class="tags">${stateTags(it)}</div></div></a>`;
  }

  // 首页和搜索结果共用顶部搜索框；边输边搜时只换下面的内容，输入框不重建，手机键盘不会收起
  function homeOrSearch(r) {
    const q = r.page === "search" ? r.q : "";
    let input = app.querySelector(".search input");
    if (!input) {
      app.innerHTML = bar('<form class="search" action="#"><input type="search" placeholder="搜索商品名、品牌或规格" ' +
        'enterkeyhint="search" autocomplete="off"></form>') + '<div id="main"></div>';
      input = app.querySelector(".search input");
      bindSearch(input);
    }
    if (document.activeElement !== input) input.value = q;
    const main = document.getElementById("main");
    if (!L.tokens(q).length) {
      const grid = data.cats.map((c, ti) =>
        `<a href="#/c/${ti}/0">${L.esc(c.name)}<small>${topCounts[ti]}</small></a>`).join("");
      main.innerHTML = note() + `<div class="grid">${grid}</div>`;
      return;
    }
    const { results, total } = L.search(data.items, q), msg = L.searchMessage(q, total);
    main.innerHTML = (msg ? `<p class="msg">${L.esc(msg)}</p>` : "") + results.map(row).join("");
  }

  function bindSearch(input) {
    input.form.addEventListener("submit", e => { e.preventDefault(); input.blur(); });
    input.addEventListener("input", () => {
      clearTimeout(timer);
      timer = setTimeout(() => {
        const href = L.searchHref(input.value), onSearch = L.parseRoute(location.hash).page === "search";
        if (href === (location.hash || "#/")) return;
        if (href === "#/" && onSearch && depth() > 0) history.back();   // 清空了搜索词：回到来时的首页
        else go(href, onSearch);                                          // 从首页开始搜记一条历史，之后的输入只替换它
      }, 250);
    });
  }

  function category(r) {
    const top = data.cats[r.top];
    if (!top) { go("#/", true); return; }
    const si = r.sub < top.subs.length ? r.sub : 0;
    const old = app.querySelector(".side");
    const sideTop = old && old.dataset.top === String(r.top) ? old.scrollTop : 0;   // 同一大类里换子分类，左栏不跳回顶部
    const side = top.subs.map((s, i) => `<a class="${i === si ? "on" : ""}" href="#/c/${r.top}/${i}" data-replace>` +
      `${L.esc(s.name)}<small>${s.n}</small></a>`).join("");
    const list = (bySub[r.top + "," + si] || []).map(row).join("");
    app.innerHTML = bar(backLink("#/") + `<span class="title">${L.esc(top.name)}</span>`) +
      `<div class="cat"><nav class="side" data-top="${r.top}">${side}</nav>` +
      `<div class="list">${list || '<p class="msg">这个分类没有商品</p>'}</div></div>`;
    app.querySelector(".side").scrollTop = sideTop;
  }

  function item(r) {
    const it = byId[r.id];
    if (!it) {
      app.innerHTML = bar(backLink("#/") + '<span class="title">商品不存在</span>') +
        '<p class="msg">没有这个商品，可能数据已更新。<a href="#/" data-replace>回首页</a></p>';
      return;
    }
    const tags = stateTags(it) + it.t.map(t => `<span class="tag">${L.esc(t)}</span>`).join("");
    const cats = it.c.filter(([t, s]) => data.cats[t] && data.cats[t].subs[s]).map(([t, s]) =>
      `<a href="#/c/${t}/${s}">${L.esc(data.cats[t].name)} / ${L.esc(data.cats[t].subs[s].name)}</a>`).join("");
    app.innerHTML = bar(backLink("#/") + `<span class="title">${L.esc(it.n)}</span>`) +
      `<div class="detail"><img alt="" src="${L.esc(L.imgSrc(it, true))}" onerror="this.onerror=null;this.src=SamsLib.PLACEHOLDER">
      <div class="body"><h1>${L.esc(it.n)}</h1><div class="spec">${L.esc(it.s)}</div>
      <div class="price">${L.formatPrice(it.p)}</div><div class="tags">${tags}</div>
      ${it.d ? `<p class="desc">${L.esc(it.d)}</p>` : ""}
      <div class="cats">所在分类：${cats}</div></div></div>` + note();
  }

  function render() {
    if (current !== null) scrolls[current] = window.scrollY;
    current = location.hash || "#/";
    lastDepth = depth();
    const r = L.parseRoute(location.hash);
    if (r.page === "cat") category(r);
    else if (r.page === "item") item(r);
    else homeOrSearch(r);
    window.scrollTo(0, scrolls[current] || 0);
  }

  app.addEventListener("click", e => {
    const a = e.target.closest("a[href^='#']");
    if (!a || !data) return;
    e.preventDefault();
    const href = a.getAttribute("href");
    if (a.hasAttribute("data-back")) goBack(href);
    else if (href !== (location.hash || "#/")) go(href, a.hasAttribute("data-replace"));
  });

  window.addEventListener("hashchange", () => {
    if (!data) return;
    if (!history.state) history.replaceState({ d: lastDepth + 1 }, "");   // 手动改了地址：当成往前走了一步
    render();
  });

  if ("scrollRestoration" in history) history.scrollRestoration = "manual";
  if (!history.state) history.replaceState({ d: 0 }, "");

  fetch(document.body.dataset.src)
    .then(res => { if (!res.ok) throw new Error(res.status); return res.json(); })
    .then(d => {
      data = d;
      topCounts = d.cats.map(() => 0);
      d.items.forEach(it => {
        byId[it.id] = it;
        it.c.forEach(([t, s]) => { (bySub[t + "," + s] = bySub[t + "," + s] || []).push(it); });
        new Set(it.c.map(c => c[0])).forEach(t => { topCounts[t]++; });
      });
      render();
    })
    .catch(() => { app.innerHTML = '<p class="msg">商品数据加载失败，请刷新重试</p>'; });
})();
```

```python
#!/usr/local/bin/python3
"""山姆商品查询 H5：生成网站文件、发布到 S3。设计见 docs/superpowers/specs/2026-10-15-sams-h5-design.md。

用法（/usr/local/bin/python3，装有 Pillow；要识别截图，必须在命令沙箱外运行）：
  sams_site.py build      由 data/ 生成 dist/（数据文件、商品图、页面）。第一次要识别约两千张截图，之后用 cache/ocr/ 的缓存
  sams_site.py publish    把 dist/ 同步到 S3 的 upload/sams/（经美国服务器 2222 → mini 服务器）
"""
import hashlib
import json
import random
import shutil
import sys
from datetime import datetime
from pathlib import Path

ROOT = Path(__file__).resolve().parent
sys.path.insert(0, str(ROOT))

import compare  # noqa: E402
import jd  # noqa: E402
import scrape  # noqa: E402
import site_data  # noqa: E402
import site_images  # noqa: E402

SRC = ROOT / "site"
DIST = ROOT / "dist"
CACHE = ROOT / "cache"


def fingerprint(data):
    return hashlib.sha1(data).hexdigest()[:8]


def render_index(template, css, js, data):
    for key in ("{{CSS}}", "{{JS}}", "{{DATA}}"):
        if key not in template:
            raise ValueError(f"index.html 模板里没有 {key}")
    return template.replace("{{CSS}}", css).replace("{{JS}}", js).replace("{{DATA}}", data)


def write(path, data):
    path.parent.mkdir(parents=True, exist_ok=True)
    path.write_bytes(data)


def build(out=DIST):
    if out.exists():
        shutil.rmtree(out)
    products = scrape.unique_items()
    top_order, sub_order = scrape.category_order()

    # 配上京东的商品用京东主图（一个 App 商品配上几个京东商品时，取名字最像的那个）
    jds = jd.jd_items()
    best = {}                                                # 商品下标 → (相似度, 京东商品)
    for i, k, s in compare.match(products, jds)[0]:
        if s > best.get(i, (0.0, None))[0]:
            best[i] = (s, jds[k])

    images, crops, missing = {}, [], []
    report = {"products": len(products), "jd_images": 0, "crops": 0}
    for i, p in enumerate(products):
        pid = site_data.product_id(p)
        src = jd.image_path(best[i][1]) if i in best else None
        if src is not None and src.exists():
            v = site_images.jd_versions(src)
            name = site_images.named(pid, v["l"])
            write(out / "img" / "t" / name, v["t"])
            write(out / "img" / "l" / name, v["l"])
            images[pid] = (f"img/t/{name}", f"img/l/{name}")
            report["jd_images"] += 1
        else:
            data = site_images.crop_for(p)
            if data is None:
                missing.append(f"{pid}\t{p['top']}/{p['sub']}\t{p['title']}\t{p['price']}")
            else:
                name = site_images.named(pid, data)
                write(out / "img" / "t" / name, data)
                images[pid] = (f"img/t/{name}", f"img/t/{name}")
                crops.append(out / "img" / "t" / name)
                report["crops"] += 1
        if (i + 1) % 200 == 0:
            print(f"  图片 {i + 1}/{len(products)}", flush=True)
    report["no_image"] = len(missing)

    data = site_data.build(products, top_order, sub_order, images, datetime.now().strftime("%Y-%m-%d %H:%M"))
    problems = site_data.check(data)
    problems += [f"{it['id']} 的图片不存在：{p}" for it in data["items"] for p in {it["it"], it["il"]}
                 if p and not (out / p).exists()]
    if problems:
        raise SystemExit("自检没过：\n  " + "\n  ".join(problems[:30]))

    blob = json.dumps(data, ensure_ascii=False, separators=(",", ":")).encode("utf-8")
    data_file = f"data/products.{fingerprint(blob)}.json"
    write(out / data_file, blob)
    js = (SRC / "lib.js").read_bytes() + b"\n" + (SRC / "app.js").read_bytes()
    css = (SRC / "app.css").read_bytes()
    js_file, css_file = f"app.{fingerprint(js)}.js", f"app.{fingerprint(css)}.css"
    write(out / js_file, js)
    write(out / css_file, css)
    html = render_index((SRC / "index.html").read_text(encoding="utf-8"), css_file, js_file, data_file)
    write(out / "index.html", html.encode("utf-8"))

    CACHE.mkdir(exist_ok=True)
    (CACHE / "no_image.txt").write_text("\n".join(missing) + "\n", encoding="utf-8")
    contact_sheet(crops, CACHE / "contact_sheet.jpg")
    report["data_file"] = data_file
    return report


def contact_sheet(paths, dest, n=100, size=120):
    """随机 100 张裁出来的图拼成一张，人工抽查用。"""
    from PIL import Image
    if not paths:
        return
    pick = random.Random(15).sample(paths, min(n, len(paths)))
    cols = 10
    sheet = Image.new("RGB", (cols * size, ((len(pick) + cols - 1) // cols) * size), "white")
    for i, p in enumerate(pick):
        im = Image.open(p).convert("RGB")
        im.thumbnail((size - 6, size - 6))
        sheet.paste(im, ((i % cols) * size + 3, (i // cols) * size + 3))
    dest.parent.mkdir(parents=True, exist_ok=True)
    sheet.save(dest, quality=85)


def main():
    cmd = sys.argv[1] if len(sys.argv) > 1 else ""
    if cmd == "build":
        r = build()
        print(f"商品 {r['products']} 个：京东图 {r['jd_images']}，截图裁图 {r['crops']}，没有图 {r['no_image']}；"
              f"数据 {r['data_file']}")
        print(f"抽查图：{CACHE / 'contact_sheet.jpg'}；没有图的商品：{CACHE / 'no_image.txt'}")
    else:
        print(__doc__)
        sys.exit(2)


if __name__ == "__main__":
    main()
```

def stage(src, dst):
    """要上传的副本：和 dist/ 一样，只是 data/*.json 换成 gzip 压缩后的字节（上传时带 Content-Encoding: gzip）。"""
    if dst.exists():
        shutil.rmtree(dst)
    shutil.copytree(src, dst)
    for p in (dst / "data").glob("*.json"):
        p.write_bytes(gzip.compress(p.read_bytes(), mtime=0))


def publish():
    if not (DIST / "index.html").exists():
        raise SystemExit("dist/ 还没生成，先运行 sams_site.py build")
    staging = CACHE / "upload"
    stage(DIST, staging)
    subprocess.run(["rsync", "-rlt", "--delete", "-e", " ".join(SSH), f"{staging}/", f"{HOST}:{REMOTE_DIR}/"], check=True)
    subprocess.run(SSH + [HOST, "bash -s"], input=REMOTE_SCRIPT.encode("utf-8"), check=True)
    shutil.rmtree(staging)
    print("已同步到 https://img.snowmeet.top/upload/sams/")

```python
"""在 mini 服务器的 nginx 配置里加上 / 删掉山姆商品查询的转发规则（设计文档 8.2）。
  python3 nginx_sams.py add <配置文件> <锚点行> <DNS>   规则插在锚点行前面，缩进和锚点行一样
  python3 nginx_sams.py remove <配置文件>               删掉加上的规则（撤回）
在服务器上：ssh … "sudo python3 - add …" < deploy/nginx_sams.py。只改文本，不重载 nginx：改完要 nginx -t 再 reload。"""
import sys

BEGIN = "# >>> 山姆商品查询 H5（sams_scrape 仓库 deploy/nginx_sams.py，2026-10-15）"
END = "# <<< 山姆商品查询 H5"
RULES = """location = /sams { return 301 /sams/; }
location ^~ /sams/ {
    resolver %s valid=300s ipv6=off;
    set $sams_origin img.snowmeet.top;
    rewrite ^/sams/$ /upload/sams/index.html break;
    rewrite ^/sams/(.*)$ /upload/sams/$1 break;
    proxy_pass https://$sams_origin;
    proxy_set_header Host img.snowmeet.top;
    proxy_ssl_server_name on;
    proxy_ssl_name img.snowmeet.top;
}"""


def add(text, anchor, dns):
    if BEGIN in text or "/sams" in text:
        raise SystemExit("配置里已经有 /sams 的规则，没改")
    n = text.count(anchor)
    if n != 1:
        raise SystemExit(f"锚点行在文件里出现了 {n} 次，必须正好 1 次，没改")
    i = text.index(anchor)
    start = text.rfind("\n", 0, i) + 1
    indent = text[start:i]
    if indent.strip():
        raise SystemExit("锚点前面还有别的文字，要用一整行（去掉行首空格），没改")
    lines = [BEGIN] + (RULES % dns).split("\n") + [END, ""]
    block = "".join(indent + l + "\n" if l else "\n" for l in lines)
    return text[:start] + block + text[start:]


def remove(text):
    if BEGIN not in text:
        raise SystemExit("配置里没有山姆的规则，没改")
    start = text.rfind("\n", 0, text.index(BEGIN)) + 1
    end = text.index("\n", text.index(END)) + 1
    if text[end:end + 1] == "\n":
        end += 1
    return text[:start] + text[end:]


def main():
    cmd, path = sys.argv[1], sys.argv[2]
    text = open(path, encoding="utf-8").read()
    if cmd == "add":
        text = add(text, sys.argv[3], sys.argv[4])
    elif cmd == "remove":
        text = remove(text)
    else:
        raise SystemExit(__doc__)
    open(path, "w", encoding="utf-8").write(text)
    print("已改：", path)


if __name__ == "__main__":
    main()
```
